# Frontend - Entre Linhas

Frontend básico para o sistema Entre Linhas, utilizando HTML, CSS e JavaScript.

Principais páginas
- `index.html`: login com feedback de erro amigável.
- `choose-reg.html` + `*-reg.html`: fluxo de cadastro separado por tipo de usuário.
- `faccionista-page.html`: página principal pós-login para buscar e filtrar usuários.
- `profile.html`: visualização de perfil de outro usuário com atalhos para chat, solicitação e avaliação.
- `my-profile.html`: visualização do próprio perfil com disponibilidade e edição de descrição (UI).
- `request.html`, `review.html`, `chat.html`: telas dedicadas para solicitações, avaliações e conversas.



## Tecnologias

- HTML
- CSS
- JavaScript
